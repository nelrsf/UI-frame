# Implementation Plan: Native Menu Customization

**Branch**: `005-native-menu-customization` | **Date**: 2026-05-11 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/005-native-menu-customization/spec.md`

## Summary

Build a simplified, Spanish-language native Electron menu that reacts to the active
theme preference (dark/light), persists that preference between restarts via the
existing NgRx + IPC persistence stack, and exposes a documented `MenuBuilder` class
so integrators can customize entries, labels, and callbacks without touching the menu
core. Light theme option is visible but disabled in this delivery; all contracts
needed for full light-theme adoption are produced now. DevTools entry is conditionally
shown only in development mode.

## Technical Context

| Attribute | Value |
|-----------|-------|
| **Language/Version** | TypeScript 5.7, Angular 19, Electron (current workspace version) |
| **Primary Dependencies** | `electron` (`Menu`, `nativeTheme`), `@ngrx/store`, `@ngrx/effects`, existing `PreferencesAdapter`, `IPC_CHANNELS` |

| **Testing** | Jasmine + Karma (`npm test`); Electron smoke script for end-to-end menu visibility |
| **Target Platform** | Electron desktop — main process (menu construction) + renderer process (NgRx state + IPC listeners) |
| **Project Type** | Desktop shell application |
| **Performance Goals** | Menu rebuild completes in < 50ms on theme change; no perceptible flash or delay to user |
| **Constraints** | contextIsolation=true, nodeIntegration=false, sandbox=true must remain unchanged; no new external packages; preload must only expose explicitly approved capabilities; all IPC channels must be declared in `channels.ts` |
| **Scale/Scope** | 1 menu builder class, 4 new IPC channels (TOGGLE_BOTTOM_PANEL, TOGGLE_SECONDARY_PANEL, THEME_CHANGED, UPDATE_PANEL_STATE), 1 new preference key, menu command dispatch via shell registry, 1 theme port for future renderer integration |

## Phase 0: Research (Complete)

Research outcomes are documented in [research.md](research.md), covering:

1. Electron `Menu` / `nativeTheme` API — rebuild strategy, `themeSource` values, platform behaviour.
2. Main-to-renderer IPC — `webContents.send` + `ipcRenderer.on` via contextBridge pattern.
3. Dev-mode detection — existing `isDev` flag in `main.ts` as condition gate for DevTools entry.
4. Theme persistence at main-process startup — reading preferences before menu is built.
5. Disabled menu items — Electron `MenuItem.enabled = false` renders item but blocks interaction.
