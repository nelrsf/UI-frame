# Implementation Plan: Light Theme Support

**Branch**: `[007-light-theme-support]` | **Date**: 2026-05-17 | **Spec**: [link](./spec.md)
**Input**: Feature specification from `/specs/007-light-theme-support/spec.md`

## Summary

Habilitar tema claro en la aplicación de escritorio creando el archivo light.css equivalente a dark.css, modificando variables.css para soportar cambio dinámico de tema, habilitando la opción "Claro" en el menu nativo, y conectando el sistema de temas con NgRx. Los componentes del shell usarán variables CSS para adaptarse automáticamente al tema activo.

## Technical Context

**Language/Version**: TypeScript 5.x / Angular 17+  
**Primary Dependencies**: Electron, Angular, NgRx, CSS Variables  
**Storage**: preferences.json (via Electron preference-store) + NgRx state  
**Testing**: Jest + Angular testing utilities  
**Target Platform**: Windows/macOS desktop (Electron)  
**Project Type**: desktop-app (Electron shell)  
**Performance Goals**: Theme switch < 1 second (SC-002)  
**Constraints**: Must reuse existing NgRx theme state, must maintain dark.css compatibility  
**Scale/Scope**: Shell v1 components only (sidebar, toolbar, tabbar, content area, bottom panel, statusbar)

## Implementation Approach

### Phase 1: CSS Theme Architecture

1. **Crear light.css**: Copiar estructura de dark.css con valores para tema claro
   - Colores de fondo claros (#ffffff, #f3f3f3, etc.)
   - Colores de texto oscuros (#1e1e1e, #333333)
   - Colores de borde y accent adaptados
   - Mismas variables CSS que dark.css (--color-*, --font-*, --spacing-*, etc.)
   - Selector: `body[data-theme="light"]` (scoped, no :root)

2. **Actualizar dark.css**: Cambiar selector de `:root` a `:root, body[data-theme="dark"]`

3. **Simplificar variables.css**: Solo importar ambos archivos:
   ```css
   @import './dark.css';
   @import './light.css';
   ```

### Phase 2: Menu Integration

3. **Habilitar themes.light**: Cambiar enabled: false → enabled: true en menu.builder.ts
4. **Verificar applyTheme**: La función existente debe manejar 'light' correctamente

### Phase 3: NgRx Integration

5. **Verificar restauración**: Confirmar que NgRx restaura tema desde preferences.json
6. **Conectar variables.css**: Asegurar que el cambio de tema activa los estilos correctos

### Phase 4: Quickstart

7. **Crear quickstart.md**: Documentar cómo usar e implementar el tema claro
